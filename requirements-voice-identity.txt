# WO-LILY-VOICE-IDENTITY-001 — durable voice-identity activation deps.
#
# Installed ON TOP of requirements.txt by the production Dockerfile to
# activate device-independent voice recognition (the ECAPA-TDNN embedder).
# Kept separate so CPU torch/torchaudio can come from PyTorch's CPU index:
#
#   1. Doc applies migrations/021_lily_voice_identity.sql (pgvector table).
#   2. The deploy image installs CPU torch/torchaudio, then this file.
#   3. LILY_VOICE_IDENTITY_ENABLED stays true (default); the embedder loads
#      and enroll/match/probe go live.
#
# Without this file installed, lily_voice_embedder.lily_voice_embedder_available()
# returns False and every voice-identity path no-ops — recognition stays
# device-linked (the localStorage/cookie group_id). CPU-only torch is
# sufficient: enrollment is post-session and the start-of-session probe is a
# single bounded forward pass, both off the vocal path.

speechbrain>=1.0.0
